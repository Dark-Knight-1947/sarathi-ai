# Tokens

## 1. What is a Token?

A token is a small unit of text that an AI model processes. Text is broken down into tokens before the model processes it.

A token can be:
- A whole word
- Part of a word
- Punctuation
- Spaces or other pieces of text


## 2. Input Tokens & Output Tokens

Input tokens are the tokens contained in the information we send to the model.
Output tokens are the tokens generated by the model in its response.

For a simple request, token usage can be thought of as input tokens + output tokens. 

We can inspect 
```python
response.usage
```
to see token usage information returned with the response.
